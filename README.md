# claude-fun

- [Ansible Field Notes](ansible/index.html) — commands, flags, playbook patterns and tricks. Open `ansible/index.html` in a browser, or serve it with GitHub Pages at `/ansible/`.
- [AWS CLI v2 Cheatsheet](aws-cli/index.html) — 17 topics, 230+ command cards with flags, sample output, IAM permissions and gotchas. Offline, no build step: open `aws-cli/index.html`, or serve at `/aws-cli/`.
- [Thai Vocab 500](thai-500/index.html) — a game that teaches the 500 most frequent Thai words: flashcards, picture match, reverse match and typing, with Leitner spaced repetition, 20 unlockable units and offline progress saving. Open `thai-500/index.html`, or serve at `/thai-500/`.
